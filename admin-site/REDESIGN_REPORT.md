# 管理サイト（admin-site）改修 報告書

日付: 2026-06-13 / 対象: `shirasame-v0/admin-site`（Next.js 16 / React 19 / Tailwind v4）
方針: 「思い切ったビジュアル刷新」＋操作感の不具合・バグ修正。**public-site のデザインは一切変更していません**（別フォルダ・別コンポーネントのため影響なし）。`.env` は閲覧していません。

検証: `npx tsc --noEmit`（クリーン）/ `npx next build`（成功・53ページ生成・プリレンダーエラー0）。

---

## 1. 何をしたか
1. public-site 以外の全フォルダを精読し、さらに**10並列のサブエージェント監査**で admin 全域を解析（**136件**の問題点を抽出・優先度付け）。
2. その上で「操作感」と「デザイン」を最優先に、確実で安全な修正を実施。

## 2. デザイン刷新（新しいブランド「Shirasame」）
参照画像（starpeggio のエディトリアル＋線画の星）に寄せ、**コバルトブルー＋インク＋オフホワイト紙**のトーンに刷新。

- `app/globals.css` を全面刷新：
  - 派手な**マゼンタの `--accent` を撤廃**（ghost/outline ボタンのホバーが毎回ピンクに光る不具合の原因）。`--accent` は控えめなニュートラルなホバー面に。
  - **ダークモードが実質無効だったバグを修正**（`@theme inline` がリテラル値を重複定義し CSS 変数を参照していなかった）。クラスベース dark に統一。
  - フォント：本文 Noto Sans JP ＋ 見出し用セリフ Cormorant Garamond（`font-display`/`.num-display`）＋ 技術ラベル用 Space Mono（`.label-mono`）。角丸を引き締め。
- ブランド要素 `components/brand.tsx`（4点スパークルの `StarMark`／`Wordmark`）と、ティール色の立方体だったローダーを**コバルトのスパークルローダー**に刷新（`loading-animation.tsx`）。
- **ブランド名を「Shirasame」に統一**（従来は「Dealer」「ガジェット紹介サイト」「Samehome Console」が混在）。
- 絵文字は不使用、アイコンは lucide（線アイコン）で統一。

## 3. シェル（操作感の根幹）
- `<main>` の**入れ子（不正HTML）と高さ/overflow の競合を解消**。`app/layout.tsx` を最小化し、`app/admin/layout.tsx` をクリーンな flex シェル（サイドバー＋トップバー＋スクロールする単一 `<main>`＋モバイル下部ナビ）に再構成。
- サイドバーの**過剰な「1文字ずつ」アニメーション（setTimeout 連鎖）を廃止**し、単一の CSS トランジションに（カクつき解消）。
- ナビを `lib/nav.ts` の**単一定義**に統一（サイドバー/ドロワー/下部ナビが食い違わない）。`aria-current` 付与。
- モバイルで**メニュー（ドロワー）を開く可視ボタン（ハンバーガー）を追加**（従来はスワイプのみで到達不能）。

## 4. 主要画面の刷新・修正
- **ダッシュボード**：ハードコードの偽データ「総閲覧数 1,234」を撤去。カウントを並列取得＋フォーカス時はバックグラウンド更新（全画面スピナーの多重発生を解消）。エディトリアルな統計カードに刷新。ルート `/` の**無限ローディングを解消**（`/admin` へリダイレクト＝重複ダッシュボードを撤去）。
- **ログイン**：ブランディング刷新、アクション別ローディング＋二重送信防止、Google ログインボタン追加、ビルドを通すため Suspense 境界を追加。
- **画像アップロード（写真登録の中核）**：**アップロード進捗表示・失敗時トースト・エラー表示**を追加（従来は投げっぱなしで無反応）。`objectURL` のリーク解消、完了コールバックを**1回だけ**正しいキーで発火、ファイル種別/サイズ検証、重複していたアップロード処理を1本に統合。
- **商品一覧**：`h-screen` 二重指定による見切れを解消。**ドラッグ並べ替えを「手動」モード限定＋専用グリップ**に（検索/絞り込み中は無効化し、保存失敗時はロールバック＋トースト）。読み込み/空/エラー状態、リロードしない SPA 削除、`alert/confirm` を共有ダイアログ/トーストへ。
- **商品 新規/編集**：下書き保存時に画像必須を解除（公開時のみ必須）、保存中のスピナー＋二重送信防止、ページ幅とヘッダーを整理。
- **レシピ管理**：**削除・タイトル編集がローカルのみでサーバー未保存だったバグを修正**（サーバー保存＋ロールバック）。テストデータのハードコードを除去、`bg-green-500` 等をテーマ Badge に、並べ替え/公開切替の失敗をトースト通知、カード刷新。
- **テーマ**：保存値を読まず毎回デフォルトに戻る不具合を修正（マウント時読込）＋保存中状態。
- **Amazonセール**：`Math.random()` で実コレクションにランダムに商品を追加していた**データ破壊バグを撤去**（タグ付き商品のみ決定論的に追加）。期限切れ自動削除の誤トーストを修正、削除に確認ダイアログ。
- **セールカレンダー（ダッシュボード内）**：`window.prompt`×3／未定義CSSクラスのボタン／2秒ポーリングを廃し、入力ダイアログ＋トースト＋イベント駆動更新に刷新。

## 5. 基盤・コード品質の修正
- `cn()` を **clsx + tailwind-merge** 化（コンポーネントの `className` 上書きが効くように）。
- トーストが約16分消えない設定を修正（自動消滅＋同時表示3件）。`tw-animate-css` を導入し**ダイアログ/トースト/メニューの開閉アニメーションを復活**。
- `lib/db/storage.ts` の `countAdmin` 二重 `.json()` バグと `images/complete` 呼び出しの引数不整合を修正。
- クライアントが呼ぶのに不在だったエンドポイントの shim を追加：`products/reorder`・`products/[id]`・`products/[id]/published`・`collections/counts`・`recipes/reorder`。
- Tailwind v4 で未使用・矛盾していた `tailwind.config.cjs`（旧HSL設定）を削除。

## 6. 今後の推奨対応（未着手・大規模/要環境のため）
監査で挙がったが、巨大ファイル or 実行環境（.env）が必要で本回未対応の主な項目：
- `settings` と `site-settings`（各約1300行・**約95%重複**）の統合。
- コレクション（並び順がローカルのみ保存／ダイアログ開閉で一覧リセット）、タグ（**グループ用ダイアログが二重描画**／毎ドロップで再取得）の修正。
- `recipes/edit`（3034行）のダークUI整合・ピンのドラッグ最適化・`lineColor` が白にリセットされる不具合。
- デッドコード整理（フォント機能一式、未使用ピン系コンポーネント、`lib/apiFetch.ts`、`api/debug/log`）。
- セキュリティ（トークンの localStorage 退避/ログ出力、`X-User-Id` の信頼、Cookie スコープ等。worker/proxy 側＝要環境）。
- ESLint 未導入（`pnpm lint` が動かない）、TypeScript `strict` 化。

完全な優先度付き一覧（67項目）は監査ワークフローの出力にあります。

## 7. 追加修正（第2回）
※ デプロイは公開先 Cloudflare に未接続のため不可。`tsc`／`next build`（**57ページ生成・エラー0**）でローカル検証済み。`.env` の値は未閲覧。

- **レシピ編集**: API（normalized）から読込時に**ピンの線色 `lineColor` が欠落して白にリセットされるデータ消失バグを修正**（公開レシピの見た目に影響）。
- **コレクション**: 削除を「トースト内ボタン」から**確認ダイアログ＋楽観的削除＋失敗ロールバック**へ。並べ替えの**サーバー保存失敗時にUI/キャッシュをロールバック＋通知**。空状態・エディトリアルなヘッダーを追加。
- **タグ**: `isGroupDialogOpen` の**ダイアログが二重に描画されていた不具合を解消**（劣る方を削除）。グループ削除の `confirm()` を共有ダイアログ化。ヘッダー刷新。
- **設定／サイト設定／ユーザー**: エディトリアルなヘッダー・幅・状態表示に統一（ユーザーはカード＋読込/空/エラー状態）。
- **不足エンドポイントの dev shim を追加**（ローカルdevで404になっていた）：`collections`・`collections/[id]`・`/inspect`・`/items`・`/sync`・`collections/reorder`・`collection-items`・`collection-items/reorder`・`amazon-sale-schedules`・`amazon-sale-schedules/[id]`。
- **デッドコード削除（12ファイル＋1エンドポイント）**: `font-manager`・`custom-font-uploader`・`pin-editor`・`pin-overlay`・`pin-detail-panel`・`recipe-display`・`product-card-simple`・`product-masonry`・`product-detail-modal`・`collection-section`・`app-initializer`・`initial-loading`・`api/debug/log`。（`lib/fonts/web-fonts.ts` は recipes/edit が使用のため保持）

## 8. なお未対応（リスク/dev環境の都合で見送り）
- `settings` と `site-settings` の**ロジック統合**（約95%重複）：ヘッダー/デザインは統一済みだが、保存ロジックの一本化は実機検証が必要なため未実施。
- `recipes/edit`（3034行）の**ダークUIの全面整合**とピンドラッグの再描画最適化（線色バグは修正済み）。
- セキュリティ（トークンの localStorage 退避・ログ出力、`X-User-Id` 信頼、Cookie スコープ、Amazonシークレットのクライアント往復）：多くが worker/proxy 側で、`.env`／実機が必要。
- ESLint 未導入（`pnpm lint` が動かない）、`[v0]` デバッグログの一括除去、TypeScript `strict` 化。
